# AlgoTrack — Algorand Transaction & Asset Tracker

## Project Overview

AlgoTrack is a beginner-friendly blockchain application based on the Algorand network. The project aims to provide a simple way to explore Algorand accounts, transactions, and digital assets.

This project is being developed as part of the Algorand Blockchain Application Developer course.

## Objectives

- Understand the basic concepts of the Algorand blockchain.
- Learn how Algorand accounts and transactions work.
- Interact with the Algorand network using developer tools and SDKs.
- Explore Algorand Standard Assets (ASAs).
- Build and test blockchain-based functionality.
- Maintain the project using GitHub and Git version control.

## Planned Features

- Algorand account information
- Transaction creation and tracking
- Transaction history
- Algorand asset exploration
- TestNet interaction
- Basic blockchain data display

## Technologies

The project will explore the following technologies during development:

- Algorand Blockchain
- Algorand SDK
- JavaScript / Node.js
- Git
- GitHub
- Algorand TestNet
